# Shared UI package

**Owner: Kripa.** Read [UX](../../docs/ux.md).

Export visual tokens, semantic controls, badges, empty states, and AssistanceControls through @steadyhand/ui. Keep DOM-page discovery, transport, and numerical filtering outside this package.

Components accept props/callbacks and expose keyboard focus and useful labels. No color-only status or fake successful live state. Popup, options, and dashboard reuse actual components and tokens.

Person 3 may use token styles in the overlay without importing React into the pointer loop. Agree on style resource paths with the extension build owner.
